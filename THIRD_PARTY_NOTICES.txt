Verbal Commands - Third-Party Notices
======================================

This mod ships the following third-party components (brief 13, "voice debug
data": Concentus/Concentus.Oggfile support Opus clip export added in Phase A;
System.Runtime.CompilerServices.Unsafe/System.Buffers/System.Numerics.Vectors/
System.Memory are their transitive BCL dependencies; NWaves and the Silero VAD
model support the Phase B1 noise/voice measurements). License texts below are
copied verbatim from each package's own license file - none written from
memory.
