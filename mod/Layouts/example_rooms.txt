// Example rooms. The mod reads this file (ExampleRooms.cs); the model is not sent it.
// Each block is one room seen from above, north at the top, one character per tile, walls included.
// '#' is a wall, '+' is a door, '.' is free floor. Every other character is a letter named above the grid.
// "letter = building" uses the game's building name (defName). A building bigger than one tile fills
// all its tiles with its letter and is cut into whole buildings from the top left.
// "head north" for a bed or "worker south" for a bench says which side the head is on, or which side
// the colonist stands on. Without it the shape in the grid decides which way the building lies.
// Drawn from five rooms of the mod author's colony. Each stool is on the tile its bench is used from.
